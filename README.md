# Yahoo Fantasy MCP

## Purpose

Yahoo Fantasy MCP is a private, personal-use integration that runs locally on a Windows computer. It connects a local AI assistant to the owner’s Yahoo Fantasy Football account for read-only analysis.

## Read-only use

The integration may retrieve the owner’s leagues, teams, rosters, standings, matchups, and available players. It does not make lineup, waiver, trade, roster, or other write changes.

## Data and privacy

This is not a public consumer service. Access is limited to the owner and the owner’s own Yahoo Fantasy league(s). Credentials and league data are stored locally and are not included in this public repository.
